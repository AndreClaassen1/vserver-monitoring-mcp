# Contributing

Thanks for your interest in this project.

## Issues

Bug reports and feature ideas are welcome as issues. Please include what you expected, what happened, and the relevant parts of your configuration (without hostnames, user names or key paths).

## Support

This is a personal project maintained in spare time. There is no guaranteed support, response time or roadmap.

## Pull requests

- Keep changes focused and include tests where it makes sense (`python -m unittest test_vserver_mcp -v`).
- All tools must stay read-only on the target server.
- Every commit must be signed off according to the [Developer Certificate of Origin](https://developercertificate.org). Use `git commit -s` to add the `Signed-off-by` line.
